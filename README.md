# Expense_Management_System
Oracle PL/SQL–based Expense Management System implementing database-side business logic, validations, and reporting using procedures, functions, and triggers.

This is a database-driven Expense Management System developed using Oracle PL/SQL. 
The project focuses on implementing business logic at the database layer, including validations, reporting, and performance optimization without using any application-layer framework.

Features:-
1)User-wise expense tracking  
2)Category-based expense management  
3)Monthly and yearly expense reports  
4)Data validation using PL/SQL logic  
5)Error handling and exception management

Technologies Used:-
1)Oracle Database
2)SQL
3)PL/SQL (Procedures, Functions, Triggers, Cursors)
